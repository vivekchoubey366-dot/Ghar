Accessibility at GHAR

We want GHAR to be usable and understandable for as many people as possible. Our website and digital property experience are designed with accessibility, inclusive interaction and responsive use in mind.

Our commitment

GHAR aims to provide a digital real-estate experience that can be accessed by people with different abilities, devices, screen sizes and interaction methods.

Accessibility is considered across property discovery, account management, property listings, communication, documents, payments and GHAR AI experiences.

Accessibility is an ongoing process We continuously review and improve the experience as new pages, features and services are introduced.

Accessible design

GHAR's interface is designed to remain usable across desktop, tablet and mobile devices.

Responsive layouts Pages adapt to different screen sizes and orientations.
Keyboard focus Interactive controls provide visible focus states when navigated using a keyboard.
Clear hierarchy Headings, sections and navigation are structured to make information easier to understand.
Reduced motion The interface respects the user's reduced-motion preference where supported.

Navigation and interaction

GHAR uses semantic navigation structures and clear interactive controls to help visitors move between important areas of the platform.

  • Skip navigation is provided on supported pages.
  • Navigation links use descriptive labels.
  • Buttons are visually distinguishable from ordinary content.
  • Keyboard focus is visibly indicated.
  • Mobile layouts are designed for touch interaction.
  • Important account and property actions are kept identifiable.

Accessible content

GHAR aims to present property and service information using clear language, meaningful headings and logical content structures.

  • Images should include meaningful alternative text when the image communicates information.
  • Decorative imagery should not be relied upon to communicate essential information.
  • Links should describe their destination or purpose.
  • Forms should provide clear labels and instructions.
  • Important information should not depend solely on colour.

Forms, accounts and transactions

GHAR contains account registration, authentication, property applications, document workflows, payment experiences and other forms.

These experiences are intended to use explicit labels, understandable instructions and meaningful validation messages so users can identify what information is required.

Account and authentication

Login, registration, OTP, password recovery and verification flows should provide clear status and error information without relying only on colour.

Property listings and discovery

Property information can include photographs, videos, floor plans, location information, pricing, amenities, verification information and other details.

Where practical, essential property information should remain available in text so that users are not required to interpret an image or visual element to understand important listing information.

Property information Price, location, area, rooms and other core details should be represented as text.
Property images Meaningful listing images should have appropriate alternative descriptions.
Map information Important location information should not depend exclusively on visual map interaction.
Filters Property search controls should have identifiable labels and usable interaction states.

GHAR AI accessibility

GHAR AI may assist users with property search, recommendations, price estimation, investment analysis, loan assistance, document assistance, property descriptions and rental-related questions.

AI-generated information should remain understandable and should not be the only way to access critical property, financial, legal or account information.

Important AI-generated information can contain errors. Users should independently verify important property, financial, legal and document information.

Assistive technology

GHAR is designed to work with common browser and device accessibility features where supported by the browser, operating system and assistive technology.

  • Screen readers
  • Keyboard navigation
  • Browser text and zoom controls
  • Mobile accessibility features
  • Reduced-motion preferences

Actual compatibility can vary depending on the browser, operating system, assistive technology and individual configuration.

Accessibility feedback

If you experience an accessibility barrier while using GHAR, please let us know. Useful feedback can include the page address, the feature you were trying to use, the device or browser involved and a description of the problem.

Need accessibility assistance? Contact the GHAR support team for help with an accessibility issue.
